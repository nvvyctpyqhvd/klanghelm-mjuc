## Overview

MJUC models three generations of classic variable-mu tube compressors with program-dependent attack and release, transformer saturation, and the warm, musical compression characteristic of vintage hardware.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Klanghelm MJUC** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Three Variants** | MkI, MkII, and MkIII models with distinct circuit character |
| **Variable-Mu** | Program-dependent gain reduction following signal envelope |
| **Transformer Color** | Input and output transformer harmonic saturation stages |
| **Wet/Dry** | Parallel wet/dry blend for New York-style parallel compression |
